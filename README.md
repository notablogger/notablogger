## Notable projects

### 🔎 Maitch Search
An AI product-discovery engine for any catalog: e-commerce, insurance, real estate and more.
- **Search Service**: an ingestion pipeline with structure-aware chunking. Descriptions, specs, features and metadata are embedded separately and linked by product ID. Qdrant or pgvector can be plugged in through config.
- **MCP server**: exposes semantic search over the ingested catalog.
- **Search Agent**: parses customer intent, builds the query and returns the most relevant products with facets so customers can refine their search.

*Commercial product. Code is not public.*

### 🤖 HelpBot
A conversational assistant grounded in an organisation's own knowledge. It ingests internal and public documents and answers according to the user's role, so customers and staff each see only what they're entitled to.

### ⚙️ [spring-xpose](https://github.com/notablogger/spring-xpose)
A Spring Boot annotation processor that generates REST and GraphQL layers at compile time from a single `@ExposeEntity` annotation. It produces no runtime reflection and no boilerplate. *Open source.*
